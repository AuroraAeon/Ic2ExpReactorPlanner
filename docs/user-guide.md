# 反应堆规划器使用指南

推荐使用 Java 17 或更新版本。在项目目录执行 `gradlew.bat run`，或双击构建后的 JAR。可在命令行指定界面语言。

```powershell
.\gradlew.bat run --args="--lang=zh-CN"
java -jar build/libs/Ic2ExpReactorPlanner-2.5.0-gtnh.1.jar --lang=zh-CN
```

英文使用 `--lang=en`。省略参数时，界面随系统语言。JAR 的具体文件名以 `build/libs` 的输出为准。

## 搭建布局

1. 选择 **GT New Horizons 2.9.0**，再填入实际安装的反应堆扩容仓数量。反应堆本体提供 3 列，每个扩容仓增加 1 列。2 个扩容仓开放 A1–F5，右侧停用槽位不可编辑。
2. 在元件列表中选择一个元件，再点击槽位放置。搜索框支持本地化名称和内部名称。`Ctrl+F` 可切到搜索框，`Esc` 退出放置工具。
3. 先用 `Ctrl+单击` 选中起始槽，随后 `Shift+单击` 另一角，或用 `Shift+方向键` 扩选。用 **填充选区** 放置当前选中的元件，用 `Delete` 清除选区。右键可清除一个槽位，中键可吸取该槽位元件及其设置。
4. 可从元件列表拖入网格，也可在槽位之间拖动。拖动槽位时按住 `Ctrl` 可复制。`Ctrl+C` 与 `Ctrl+V` 可复制、粘贴选区。粘贴以当前槽位为左上角，保留初始热量和自动更换设置。`Ctrl+Z` 与 `Ctrl+Y` 撤销和重做。
5. **文件 → 打开布局** 和 **保存布局** 使用包含布局代码的纯文本。可通过代码旁的按钮复制、粘贴完整布局。导入未指定游戏版本的旧代码前，先在界面选择对应版本。旧代码若含已淘汰的元件，导入后会列出移除项。

## 模拟与读取结果

- 在 **运行设置** 选择 EU 或流体模式、初始堆温和模拟时限。GTNH 流体模式需要 6 个扩容仓。传输量按每秒一次的反应堆更新计算，单位为 mB。
- 需要红石节拍时勾选脉冲，在 **脉冲设置** 设置开启、关闭时长和两条堆温阈值。**元件** 标签页显示所选槽位，支持设置自动更换阈值和更换停堆时长。
- 点击 **模拟** 或按 `F5`。进度条在窗口右下角，长任务可以取消。底栏会显示模拟时间、平均输出和峰值堆温，以及首个失效的元件、位置和时间。GTNH 网格编辑后会试算最多 20 秒，完整燃料周期仍需手动运行。
- 模拟后选择槽位查看可用的峰值热量、剩余寿命和元件记录。红色槽位表示失效，橙色表示残留热量。两次成功运行后可在 **比较** 查看差异，勾选锁定可固定上次对照。
- `EU/t` 和 `HU/t` 中的 `t` 是游戏刻。正常游戏速度下每秒 20 游戏刻，模拟每秒更新反应堆一次。`EU` 和 `HU` 表示累计输出。

## 钍增殖与真空冷冻

钍燃料棒耗尽后，报告会按单联、二联和四联统计枯竭燃料棒，并按 2.9.0 热力离心机配方计算镥粉、钍粉和铁粉。未完成燃料周期的燃料棒不会计入产物。

在 **真空冷冻循环** 标签页打开外置冷却选项，填写交换阈值、每种冷却单元的冷备用量、并行冷冻机台数和超频级数。各台常规真空冷冻机每次处理一个配方。完整结果包含交换量、恢复量、队列、损毁、第一次缺货时间和耗电量。冷冻配置是本次运行条件，分享普通布局代码时请另外给出这些值。

仓库的 [examples](../examples) 提供两份「2 个扩容仓、11 根四联钍燃料棒」布局，用 **文件 → 打开布局** 载入。冷却机配置、跑完一轮的产物和验证范围见[布局说明](thorium-and-vacuum.md)。
